# TheMoun

**An integrated capture workstation for cards, coins, and slabs. The bench is where margin leaks.**

[![Website](https://img.shields.io/badge/Web-themoun.com-2ea44f)](https://themoun.com)
![Status](https://img.shields.io/badge/Status-Hardware%20Program-d29922)
![Line](https://img.shields.io/badge/EPIC%20Line-Eco%20%E2%86%92%20Pro%20%E2%86%92%20Investor%20%E2%86%92%20Curator-6f42c1)

Sellers and graders assemble capture setups from unrelated SKUs — light tents, ring lights, tripods, centering templates — producing glare, inconsistent framing, and poor signal for AI grading, image search, and marketplace comps.

**TheMoun is one purpose-built imaging bench:** a specimen deck, controlled task lighting, and repeatable phone-capture geometry designed as a single system. Clean, consistent imagery feeds directly into the [RawGraded](https://rawgraded.com) AI layer.

**Design highlights**

- Unified TCG + coin reference geometry via removable translucent guides
- Flippable mark-free deck inserts for clean AI/listing imagery
- Medical-grade silicone edge protection
- Modular serviceability — replaceable wear parts instead of glued monoliths
